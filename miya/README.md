# 🦊 Мия: голосовой ИИ-помощник

Мия — милая и нежная лисичка, твоя заботливая собеседница. Говорит и понимает по-русски,
помнит ваши разговоры, рассказывает свежие новости и сама пишет первой: утром будит, днём
напоминает поесть и размяться, а вечером спрашивает, как прошёл день.

Работает как PWA на **iPhone** (Safari → «На экран Домой»), **Mac** и **Windows** (Chrome, Edge, Safari).
Всё бесплатно: хостинг Vercel (Hobby), Gemini API (бесплатный тариф), Upstash Redis (бесплатный тариф).

## Как это устроено

```
 Браузер / PWA (public/)                       Vercel Functions (api/)                Внешние сервисы
 ┌────────────────────────────┐   HTTPS   ┌──────────────────────────────┐
 │ чат + анимированная лиса    │ ───────▶ │ /api/chat       ответ Мии    │ ──▶ Gemini API (ключ только тут)
 │ Web Speech API: речь ⇄ текст│          │ /api/transcribe аудио→текст  │ ──▶ Gemini API
 │ Service Worker: push, офлайн│ ◀─────── │ /api/history, /api/memory    │ ◀─▶ Upstash Redis (память)
 └────────────────────────────┘   push    │ /api/subscribe  web push     │ ──▶ RSS-ленты новостей
                ▲                          │ /api/cron       пишет первой │
                └──── Web Push ◀────────── └──────────────────────────────┘ ◀── Vercel Cron (по расписанию)
```

- **Мозг**: Gemini через REST API. Если основная модель недоступна или исчерпан лимит, автоматически
  пробуются резервные (`gemini-flash-latest` → `gemini-2.5-flash` → lite-версии).
- **Память**: вся переписка, отдельные факты о тебе (Мия сама решает, что запомнить, через function calling)
  и сжатое резюме старых разговоров. Всё это хранится в Redis и общее для всех твоих устройств.
- **Новости**: Мия вызывает функцию `get_news`, сервер забирает свежие заголовки из RSS
  (Google Новости, Лента, РИА, ТАСС), и Мия пересказывает их своими словами.
- **Голос**: распознавание через встроенный в браузер Web Speech API. Если его нет или он не работает
  (Firefox, некоторые версии iOS в режиме PWA), звук записывается и расшифровывается через Gemini.
  Озвучка идёт через `speechSynthesis`, при этом подбирается женский русский голос (Milena на Apple,
  Svetlana/Dariya на Windows, «Google русский» в Chrome).
- **Пишет первой**: Vercel Cron вызывает `/api/cron`, Мия генерирует тёплое сообщение с учётом памяти,
  кладёт его в чат и отправляет push на все подписанные устройства.

## Развёртывание (примерно 15 минут)

### 1. Ключ Gemini
Открой [Google AI Studio → API keys](https://aistudio.google.com/apikey) и создай ключ (бесплатно).

> На бесплатном тарифе Google может использовать запросы для улучшения своих моделей. Не рассказывай Мие
> пароли и другие секреты.

### 2. Проект на Vercel
1. Зайди на [vercel.com](https://vercel.com), войди через GitHub и нажми **Add New → Project**.
2. Выбери репозиторий `MaccaaaYT/MaccaaaYT`.
3. В поле **Root Directory** укажи **`miya`**. Framework Preset: **Other**. Build Command оставь пустым.
4. Пока не нажимай Deploy: сначала добавь переменные (шаг 4).

### 3. Хранилище памяти (Upstash Redis)
В проекте Vercel открой **Storage → Create Database → Upstash (Redis)**, выбери бесплатный план
и подключи базу к проекту. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.

### 4. Переменные окружения
**Settings → Environment Variables**:

| Переменная | Значение |
|---|---|
| `GEMINI_API_KEY` | ключ из шага 1 |
| `APP_PASSWORD` | пароль для входа в приложение (**обязательно**, иначе любой, кто узнает адрес, будет тратить твой лимит) |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` | сгенерируй локально командой `npm install && npm run vapid` |
| `VAPID_SUBJECT` | `mailto:твоя-почта@example.com` |
| `CRON_SECRET` | любая длинная случайная строка (Vercel Cron передаёт её сам) |
| `MIYA_TIMEZONE` | необязательно, по умолчанию `Europe/Moscow` |
| `USER_NAME` | необязательно: как тебя зовут (можно указать и в настройках приложения) |
| `GEMINI_MODEL` | необязательно: конкретная модель, например `gemini-2.5-flash` |

После этого нажми **Deploy** (или **Redeploy**, если проект уже создан).

### 5. Установка на устройства
- **iPhone** (iOS 16.4+): открой адрес в **Safari** → «Поделиться» → **«На экран Домой»**. Открой Мию
  с иконки, войди, затем в ⚙️ Настройках нажми **«Включить уведомления»**. Push на iPhone приходят
  только приложению, установленному на экран «Домой».
- **Mac**: в Safari выбери «Файл → Добавить в Dock», в Chrome нажми на значок установки в адресной строке.
- **Windows**: в Chrome или Edge нажми на значок установки в адресной строке.

На каждом устройстве один раз включи уведомления в настройках Мии и нажми «Проверить».

## Расписание «Мия пишет первой»

| Время | Что делает Мия |
|---|---|
| 08:00 | будит: пора проснуться, умыться, выпить воды |
| 11:00 | просит встать из-за стола и размяться |
| 13:00 | напоминает пообедать |
| 16:00 | снова разминка и отдых для глаз |
| 21:00 | спрашивает, как прошёл день |

Каждый слот можно выключить в настройках приложения. Время и тексты меняются в `lib/schedule.js`.
После изменения времени или часового пояса пересобери расписание:

```bash
MIYA_TIMEZONE=Asia/Novosibirsk npm run crons   # перепишет crons в vercel.json (в UTC)
```

**Точность.** На бесплатном тарифе Vercel Cron запускает каждую задачу раз в день и не гарантирует точную
минуту: задача на 08:00 может сработать в любой момент с 08:00 до 08:59. Если нужна точность,
подключи бесплатный внешний планировщик, например [cron-job.org](https://cron-job.org):
- URL: `https://<твой-проект>.vercel.app/api/cron?key=<CRON_SECRET>`
- интервал: каждые 10–15 минут.

Сервер сам определяет, какой слот наступил, и не отправит одно напоминание дважды за день.

Ручная проверка (сразу отправит вечерний вопрос):
```
https://<твой-проект>.vercel.app/api/cron?slot=evening&force=1&key=<CRON_SECRET>
```

## Локальная разработка

```bash
cd miya
npm install
cp .env.example .env      # впиши GEMINI_API_KEY (остальное по желанию)
npm run dev               # http://localhost:3000
npm test                  # тесты без сети
```

Без `GEMINI_API_KEY` Мия работает в демо-режиме: повторяет за тобой, а по расписанию шлёт заготовленные фразы.
Без Redis память живёт только до перезапуска сервера. Распознаванию речи и push нужен HTTPS
(или `localhost`).

## Ограничения и советы
- **Распознавание речи**: лучше всего работает в Chrome, Edge и Safari. В Firefox и там, где встроенное
  распознавание недоступно, используется запись и расшифровка через Gemini. Способ можно выбрать в настройках.
- **Лимиты Gemini**: на бесплатном тарифе действуют ограничения на число запросов в минуту и в день.
  Когда лимит исчерпан, Мия попробует резервную модель, а если не получится, вежливо попросит подождать.
- **Голос**: качество зависит от системы. На Mac и iPhone лучший голос Milena (Enhanced), его можно
  скачать в «Настройки → Универсальный доступ → Устный контент → Голоса».
- **Конфиденциальность**: пароль хранится в браузере устройства. Кнопка «Выйти на этом устройстве» удаляет
  его и отписывает устройство от уведомлений. Память можно посмотреть и очистить в настройках.
- Мия не врач: при проблемах со здоровьем она посоветует обратиться к специалисту.
